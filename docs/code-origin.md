# 代码来源与许可说明

本文说明当前可以核对到的依赖、开发记录和待办，不是项目许可证，也不是法律意见或完整的代码来源审计结论。

## 项目定位

ReveS3 是用于连接 S3 客户端与 Cloudreve HTTP API 的非官方适配项目，与 Cloudreve 官方没有隶属关系。项目名称中的 Cloudreve、第三方名称及链接仅用于说明兼容对象和代码来源；本文不授予这些名称、标识或素材的使用权。

当前仅把 ReveS3 用作项目展示名，没有为该名称作商标或全球重名检索。不要使用 Cloudreve 官方 Logo，也不要在仓库介绍中声称这是官方组件或已获得官方认可。

## 当前实现和依赖

| 部分 | 当前来源或实现方式 | 核对依据 |
| --- | --- | --- |
| Cloudreve 连接 | `internal/` 中的适配代码通过 HTTP 请求登录、文件和上传 API | 当前实现及 `go.mod`；未列为 Cloudreve Go 模块依赖 |
| S3 协议服务 | `github.com/versity/versitygw` v1.11.0 | `go.mod` 与第三方声明；Apache-2.0 |

版本以 [go.mod](../go.mod) / [go.sum](../go.sum) 为准，许可证原文见 [third-party/NOTICES.txt](../third-party/NOTICES.txt)。API 名称、JSON 字段或单纯没有上游模块依赖，都不能单独证明没有复制受保护的实现代码。

1. 随源码和程序包保留适用的许可证、版权声明、NOTICE 与其他必需文件。
2. 保留实际修改过的第三方文件要求的修改说明；不要删除原作者信息。
3. 如许可证要求提供对应源码或其他材料，按其具体条件履行；不要只提供一个不完整的项目链接。
4. 升级依赖后重新收集并核对声明，不把旧版声明直接当作新版结论。
